# ALFA Media Bot V5 Commands

## Yangiliklar
- "Qo'shiq MP3" tugmasi olib tashlandi.
- Format tanlashda:
  - MP4 Video
  - MP3 Ovoz
  - Bekor qilish
- / yozilganda foydalanuvchi buyruqlari chiqadi.
- Admin uchun ko'proq commandlar qo'shildi.
- Admin panel keyboard holatda qoladi.

## Ishga tushirish
```bash
source venv/bin/activate
pip install -U pip setuptools wheel
pip install -r requirements.txt
python3 main.py
```
